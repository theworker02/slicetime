# slicetime

Slice identifiers and time tokens for idempotent workflows.

**Site:** https://theworker02.github.io/slicetime/

## Install / run

```bash
git clone https://github.com/theworker02/slicetime.git
cd slicetime
node src/cli.js
node --test
```
